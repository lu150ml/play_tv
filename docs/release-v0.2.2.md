# Server Xtreme v0.2.2

## Correcoes principais

- Corrige Remember Me e Keep Watching entre reinicializacoes do aplicativo.
- Protege a senha lembrada usando o armazenamento seguro do Windows.
- Salva progresso em pausa e considera conteudo concluido a partir de 95%.
- Remove o historico completo de uma serie, incluindo episodios.
- Aceita servidores Xtream com catalogos parciais e URLs com `player_api.php`.
- Adiciona volume funcional e limita Pular abertura a episodios.
- Usa uma unica instancia do aplicativo e bloqueia navegacao externa insegura.

## Downloads

- `Server Xtreme-Setup-0.2.2.exe`: instalador para Windows x64.
- `Server Xtreme-0.2.2-portable.exe`: versao portatil para Windows x64.

Os executaveis nao possuem assinatura digital. Confira o arquivo `.sha256` correspondente antes de executar.
